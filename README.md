# AI伏せ字（体験ページ）

AIに貼る前に、氏名・住所・電話番号・メール・会社名を [氏名1] のような伏せ字に置き換える無料ツールです。
判定も置き換えも、ブラウザの中だけで行います。文章をサーバーに送る仕組みはありません。

- 体験ページ：https://micoficial.github.io/ai-fuseji/
- Chrome 拡張機能：https://chromewebstore.google.com/detail/clhnanhhikamfccidiibgbbfhnkgefjo
