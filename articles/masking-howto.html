AI伏せ字無料で試す

ChatGPTに貼る前の個人情報マスキング、3つのやり方（手作業・Wordの置換・自動）

「お客様の名前が入ったメールを、ChatGPTに要約してもらいたい。でも、名前をそのまま貼るのは気が引ける」。
そんなときに使うのが マスキング（伏せ字への置き換え）です。

この記事では、特別な道具がなくてもできる方法から、自動でやる方法まで、3つのやり方を比べます。どれを選んでも、最後に目で確かめる ことだけは共通です。

マスキングの基本：「消す」より「置き換える」

名前を ■■■ や ○○ で消すと、AIは「誰が」「誰に」を区別できなくなり、答えがちぐはぐになりがちです。
おすすめは、[氏名1]、[氏名2]、[会社1] のように、種類と番号で置き換える ことです。

  • 同じ人は、文章のどこでも同じ伏せ字にする（山田さん → いつも [氏名1]）
  • 別の人には、別の番号をつける（鈴木さん → [氏名2]）
  • 「様」「さん」「御中」は伏せ字の外に残す（[氏名1]様）

こうしておけば、AIは「[氏名1]様への返信」として自然な文章を作れます。そして答えの [氏名1] を山田に戻せば完成です。

やり方1：手作業で書き換える（短い文章向け）

数行のメールなら、メモ帳に貼って自分で書き換えるのがいちばん早いです。

  1. 文章をメモ帳などに貼る
  2. 名前、会社名、住所、電話番号、メールアドレスを探して、伏せ字に書き換える
  3. 書き換えた対応（[氏名1]＝山田太郎 など）を、手元にメモしておく
  4. 伏せ字の文章をAIに貼る

向いている： 3〜5行の短いメール
弱いところ： 長い文章では見落としが出る。署名の名前や、本文の途中の電話番号を忘れやすい

やり方2：WordやExcelの「置換」を使う（同じ名前が何度も出る文章向け）

議事録や報告書のように、同じ名前が何度も出てくる文章なら、置換機能が便利です。

  1. 文章をWordに貼る
  2. Ctrl＋H で「置換」を開く
  3. 「検索する文字列」に 山田太郎、「置換後の文字列」に [氏名1] を入れて「すべて置換」
  4. 名字だけ（山田）でも出てくるなら、それも同じ伏せ字で置換する
  5. 人数・会社の数だけ繰り返す

向いている： 登場人物が決まっている議事録、毎月同じ取引先が出てくる報告書
弱いところ： 置換する言葉は自分で見つける必要がある。電話番号やメールのように毎回ちがう情報は、一つずつ探すことになる

よくある見落とし

  • メールの最後の 署名（名前、携帯番号、メールアドレス）
  • 「担当：佐藤」 のような短い書き方
  • 全角と半角のちがい（０３-１２３４ と 03-1234 は別の文字として扱われる）
  • 本文に引用された 前のメール（返信の下にぶら下がっている部分）

やり方3：自動で置き換える道具を使う（毎日使う人向け）

毎日のようにAIを使うなら、置き換えを自動にすると、手間と見落としが減ります。
選ぶときは、次の3点を確かめてください。

  1. 文章を外部のサーバーに送らないか（マスキングのために別の会社へ送っては意味がない）
  2. AIの答えを、元の名前に戻せるか（戻せないと、結局手で直すことになる）
  3. 伏せすぎないか（「お客様」「ご担当者様」まで伏せると、文章が読みにくくなる）

私たち（合同会社mico）は、この3点を満たす無料の道具「AI伏せ字」を作りました。名前・会社名・住所・電話番号・メールなどを [氏名1] のような伏せ字に置き換え、AIの答えを元に戻せます。処理はすべてブラウザの中で行い、文章は外部に送信しません。

インストール不要の体験ページ：こちら

あわせてChatGPT・Gemini・Copilotの「学習させない設定」も（ただし伏せ字の代わりにはならない）

マスキングとは別に、使っているAIの「入力した内容を学習に使わない」設定も確かめておきましょう。項目の名前はときどき変わるので、近い名前のものを探してください（2026年10月時点）。

  • ChatGPT：設定 → データコントロール → 「すべての人のためにモデルを改善する」をオフ
  • Gemini（個人のGoogleアカウント）：設定とヘルプ → アクティビティ → 「Gemini アプリ アクティビティ」（新しい画面では「アクティビティを保存」）をオフ。会社の Google Workspace のアカウントは、管理者の設定に従います（詳しくは Geminiに個人情報はどこまで入れていい？）
  • Copilot（個人のMicrosoftアカウント）：プロフィール → プライバシー → 「モデルのトレーニング」の項目をオフ。会社で契約した Microsoft 365 Copilot は、会社の管理です（詳しくは Copilotに個人情報はどこまで入れていい？）
  • Claude：設定 → プライバシー → 学習への利用の項目をオフ（詳しくは Claudeに個人情報はどこまで入れていい？）

ただし、オフにしても、入力した文章はAIの会社のサーバーに送られ、一定期間保存されることがあります。「学習されない」と「外に出ていない」は別のことです。名前や電話番号は、設定とは別に伏せ字にしてから貼るのが確実です。

PDFの「黒塗り」はAIに読まれることがある

PDFの上に黒い四角を重ねただけの黒塗りは、見た目が隠れているだけで、下の文字は残っています。ChatGPTなどにPDFをアップロードすると、AIは見た目ではなく中の文字を読むので、黒塗りした名前もそのまま伝わることがあります（「pdf 黒塗り 見える」と調べる人が多いのはこのためです）。

  • 確かめ方：黒塗りしたPDFを開いて、全部選択（Ctrl+A）→コピー→メモ帳に貼る。隠したはずの名前が出てきたら、文字は残っています
  • 確実なやり方：PDFにする前の Word・Excel で、名前そのものを [氏名1] のように置き換えてからPDFにする。元のファイルがなければ、PDFの文字をコピーして伏せ字にし、文章としてAIに貼る
  • 紙をスキャンした書類：ペンの黒塗りは、スキャンの明るさによって透けて読めることがあります。AIに渡す前に、画像を拡大して確かめてください

どの方法でも、最後に必ずやること

  • 伏せ字にした文章を、送る前に一度読む。 自動の道具でも、判定は機械的なルールなので見落としがありえます
  • マイナンバー、口座番号、健康の情報は、伏せ字にしても貼らない（理由は https://micoficial.github.io/ai-fuseji/articles/customer-info-chatgpt.html ）
  • 会社のルールを確認する。 ルールがなければ、ひな形から作ると早いです：https://micoficial.github.io/ai-fuseji/articles/ai-shanai-rule.html
  • どこを隠すか迷ったら、12か所の一覧：https://micoficial.github.io/ai-fuseji/articles/masking-kasho.html
  • ほかの道具と比べたいなら、無料・買い切り・月額の比較：https://micoficial.github.io/ai-fuseji/articles/masking-tool.html
