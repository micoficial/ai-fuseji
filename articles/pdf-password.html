PDFのパスワードを解除して保存する方法（Chrome・Edge、無料）

パスワードの付いたPDFは、開くたびに入力が要るうえ、結合や分割の道具に読み込めないことがよくあります。年末調整で集めた源泉徴収票や控除証明書をまとめようとして、ここで止まる人は少なくありません。

パスワードが分かっているPDFなら、いつも使っている Chrome か Edge だけで、パスワードの無いPDFとして保存し直せます。無料で、ソフトを入れる必要も、ファイルをどこかのサイトにアップロードする必要もありません。

あわせて、反対に個人情報の入ったPDFにパスワードを付けたいときに、外部のサイトを使わずに済ませる方法もまとめます（2026年11月2日時点の内容です）。

この記事は、自分あてのファイルや、社内で扱いを任されているファイルのパスワードを外す話です。パスワードが分からないPDFを開けるようにする方法ではありません。

Chromeでパスワードを解除して保存する

  1. PDFのファイルを Chrome の画面にドラッグして開く（またはファイルを右クリック →「プログラムから開く」→ Google Chrome）
  2. パスワードの入力欄が出るので、開くためのパスワードを入れる
  3. 中身が表示されたら、Ctrl + P（Macは command + P）で印刷の画面を出す
  4. 「送信先」を「PDFに保存」に変える
  5. 「保存」を押し、ファイル名を付けて保存する

保存したPDFは、開いてもパスワードを聞かれません。ページは元のまま、文字も選べる状態で残ることがほとんどです。

Edgeでパスワードを解除して保存する

Windows の会社PCでは、PDFをダブルクリックすると Edge で開くことが多いはずです。やり方は Chrome とほぼ同じです。

  1. PDFを Edge で開き、パスワードを入れる
  2. Ctrl + P で印刷の画面を出す
  3. 「プリンター」を「PDF として保存」に変える（「Microsoft Print to PDF」でも可）
  4. 「保存」を押す

解除して保存できないときに考えられること

  • パスワードを入れても開けない：開くためのパスワードが違います。源泉徴収票などは、会社が社員番号や生年月日をもとに決めていることが多いので、配った担当者に確かめてください。
  • 開けるのに、印刷の画面が出ない・印刷が灰色：作った人が「印刷を許可しない」設定にしているPDFです。この方法では保存し直せません。作った人に、制限の無いファイルをもらってください。
  • 保存したPDFの文字が選べない・少しぼやける：元のPDFがスキャン画像だった場合や、印刷用に画像として描かれる部分がある場合に起きます。中身を見る・まとめる目的なら、そのまま使えます。
  • スマホ・iPhone で同じことをしたい：iPhone でも、ファイルを開いて共有 →「プリント」→ プレビューを広げて共有、の流れでPDFを作り直せますが、手順が端末ごとに違います。会社の書類は、PCで扱うほうが確実です。

無料の「パスワード解除サイト」に上げる前に

「pdf パスワード 解除」と検索すると、ファイルをアップロードして解除する無料サイトが多く出てきます。便利ですが、中身ごと相手のサーバーに送ることになります。

パスワードが付いているのは、たいてい見られては困る書類だからです。源泉徴収票には氏名・住所・給与の額、控除証明書には家族の名前や保険の契約内容、場合によってはマイナンバーも載っています。それを外のサイトに上げるのは、パスワードを付けた意味を自分で消すことになります。

上の Chrome・Edge のやり方なら、ファイルはPCの中から出ません。

反対に、PDFにパスワードを付けたいとき（オフライン・無料）

総務の人が、源泉徴収票や給与明細をPDFで社員に渡すときは、パスワードを付けたくなります。ここでも、外部のサイトに上げずに済ませる方法があります。

  • Word（Windows・Microsoft 365 など）：元の書類が Word なら、「ファイル」→「エクスポート」（または「名前を付けて保存」）で PDF を選び、「オプション」の中の「ドキュメントをパスワードで暗号化する」に印を付けて保存します。
  • Mac の「プレビュー」：PDFを開き、「ファイル」→「書き出す」の画面でパスワードを設定できます（macOS の版によって「暗号化」または「アクセス権」の項目にあります）。
  • インストール型の無料ソフト：CubePDF など、PCの中で動くPDF作成ソフトには、パスワードを付ける機能が入っているものがあります。会社のPCにソフトを入れてよいかは、社内のルールで確かめてください。

なお、無料の Adobe Acrobat Reader には、パスワードを付ける機能はありません（有料の Acrobat が要ります）。

パスワードは、ファイルと別の手段で伝える

パスワード付きのPDFをメールで送り、続けて同じメールアドレスにパスワードを送るやり方は「PPAP」と呼ばれ、メールが盗み見られたら両方とも見られるため、効き目が薄いと言われています。パスワードは、電話や社内チャットなど別の手段で伝えるか、あらかじめ本人と決めておく（社員番号と誕生日の組み合わせなど）ようにしましょう。

また、源泉徴収票をPDFなどの電子データで渡すには、前もって本人の承諾を取っておく必要があります。紙を希望する人には紙で渡せるようにしておきます。

パスワードを外したら：まとめる・軽くする・見せない所を消す

パスワードを外したPDFは、普通のPDFとして扱えます。私たちが作った次のページは、どれもブラウザの中だけで動き、ファイルを送信しません（ページを開いた後にネットを切っても動きます）。

  • まとめる：PDF結合（アップロードなし）　1人分の源泉徴収票と控除証明書を1つに
  • 見せない所を消す：PDF墨消し　マイナンバーなどを、下の文字ごと消します
  • 軽くする：PDF圧縮（アップロードなし）
  • 分ける：PDFの分割・ページの抜き出し

パスワードを外したファイルは、そのぶん守りが薄くなります。作業が終わったら、外したほうのファイルは消すか、社内の決まった場所にだけ置いてください。

まとめ

  • パスワードが分かっているPDFは、Chrome・Edge で開いて「PDFに保存」で印刷すれば、パスワード無しで保存できる
  • 開けるのに印刷できないPDFは、作った人が印刷を禁止している。作った人に頼む
  • 個人情報の入ったPDFを、解除サイト・設定サイトにアップロードしない
  • パスワードを付けるなら、Word の PDF 保存・Mac のプレビュー・PCで動く無料ソフトで
  • パスワードはファイルと別の手段で伝える

パスワードを外したPDFを、PCの外に出さずに1つに。
源泉徴収票や控除証明書のPDFを、ブラウザの中だけで結合します。ファイルはどこにも送りません。

無料で結合する（インストール不要）

毎回使うなら、ブラウザに入れておけます（無料）→ Chrome拡張「PDF結合」 ／ Edgeアドオン「PDF結合」

ほかの無料ツール（アップロードなし）：PDF結合（サイズをA4にそろえる） ／ PDF墨消し ／ PDF圧縮 ／ 画像の文字読み取り（OCR）
