AI伏せ字無料で試す

ChatGPTに個人情報を学習させない設定｜オフにする場所・一時チャット・会社のプランとの違い

「ChatGPTに入れた顧客の名前が、学習されてほかの人の答えに出てきたら困る」。そう思って設定を探す人が増えています。
この記事では、学習させない設定の場所と、設定だけでは防げないことを順に書きます。

※ 画面の名前や場所、保存の期間は、OpenAI の更新で変わることがあります。最後は OpenAI の公式ヘルプ（データコントロール・一時チャット）で確かめてください。

1. 学習させない設定の場所（パソコン・スマホ）

個人の無料版・Plus・Pro では、何も変えないと、会話の内容が AI の改善（学習）に使われることがあります。止める場所は1か所です。

  • パソコン（ブラウザ・アプリ）：右上（または左下）のアカウント →「設定」→「データコントロール」→「すべての人のためにモデルを改善する」をオフ
  • スマホのアプリ：左上のメニュー → 自分の名前 →「データコントロール」→ 同じ項目をオフ
  • この設定はアカウント全体にかかります。パソコンでオフにすれば、同じアカウントのスマホでもオフです
  • オフにしても、チャットの履歴はこれまでどおり残ります。履歴が消えるわけではありません

2. その場かぎりなら「一時チャット」

設定はそのままで、特定の会話だけ学習に使わせたくないときは、一時チャット（Temporary Chat）を使います。画面上部の切り替えから始められます。

  • 履歴に残らず、メモリー（ChatGPTが覚えておく情報）も作られず、学習にも使われないと案内されています
  • ただし30日間は OpenAI のサーバーに保存され、不正利用の確認のために見られることがあるとされています。「すぐ消える」わけではありません

3. 見落としやすい2つ：メモリーと「いいね」

  • メモリー：ChatGPT は会話の中から「この人は◯◯社の総務」のような情報を覚えておくことがあります。設定 →「パーソナライズ」→「メモリー」で、覚えた内容を見て消せます。仕事の顧客情報が入っていないか、ときどき確かめてください
  • 回答への評価（いいね・よくないね）：押すと、その会話がフィードバックとして OpenAI に送られます。扱いは公式ヘルプで確かめられますが、顧客情報の入った会話では押さないのが無難です

4. 会社が契約したプランは最初から学習に使われない

ChatGPT の Business（旧 Team）・Enterprise・Edu や API は、入力を学習に使わない扱いが標準です。上の設定を探す必要はありません。

まず、いま自分がどちらで使っているかを確かめてください。個人のメールアドレスで入っているなら個人向けのプランで、1. の設定が必要です。会社のアカウントで使うと管理者に何が見えるかは、ChatGPTを会社で使うとバレる？にまとめています。

5. オフにしても防げないこと

「学習されない」と「外に出ていない」は同じではありません。設定をオフにしても、次のことは変わりません。

  1. 入力した文章は OpenAI のサーバーに送られて処理される：会社やお客様との約束で「外部のサービスに預けない」と決めているなら、設定に関係なく入れられません
  2. すでに学習に使われた分は取り消せない：オフにした後の会話から止まります。履歴を消したときの扱いは履歴を削除すると学習はどうなる？へ
  3. 人の手の誤り：共有リンクの作りっぱなし、別の人の画面での入力、貼る相手の取り違えは、設定では止まりません

入れてしまった直後なら、AIに個人情報を入れてしまったら（最初の10分でやること）を見てください。社内でそろえるなら社内ルールの例がそのまま使えます。

設定と一緒にやりたいのは、貼る前に伏せ字にすること

「山田太郎様」を [氏名1]様、「090-1234-5678」を [電話1] にしてから貼れば、ChatGPT に頼めることはほとんど変わりません。返ってきた答えの伏せ字を元に戻せば完成です。名前や番号がそもそも送られないので、設定のオン・オフや会社のプランに左右されません。

私たち（合同会社mico）は、この置き換えと戻す作業をブラウザの中だけで行う無料の道具「AI伏せ字」を作りました。文章は外部に送信しません。ChatGPT のほか、Claude・Gemini・Copilot に貼る前でも使えます。
