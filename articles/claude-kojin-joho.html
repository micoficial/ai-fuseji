Claudeに個人情報はどこまで入れていい？｜学習させない設定と、仕事で使うときの線引き

文章がうまいので、お客様へのメールや報告書の下書きを Claude に頼む人が増えています。
では、お客様の名前や電話番号が入った文章を、そのまま貼ってよいのでしょうか。

※ 設定の名前や場所、保存の期間は、Anthropic の更新で変わることがあります。最後は Claude の公式ヘルプとプライバシーポリシーで確かめてください。

1. 個人向けのプランは「学習に使うか」を自分で選ぶ

Claude の無料・Pro・Max（個人向けのプラン）では、2025年秋から、チャットの内容を AI の改善（学習）に使ってよいかを利用者が選ぶ形になりました。オンのままだと、入力した内容が学習に使われることがあります。

  • 設定の場所：左下のアカウント →「設定」→「プライバシー」→「Claudeの改善にご協力ください」をオフ
  • この設定はアカウント全体にかかります。設定がオンのままでも、シークレット（インコグニート）チャットで始めた会話は改善（学習）に使われないと案内されています
  • オンにすると、オンにした後の新しい（または再開した）チャットが、個人を特定しにくい形で最長5年保たれることがあります。オフにしても、すでに学習に使われた分は取り消せません
  • 削除したチャットは履歴からすぐ消え、Anthropic のサーバーからも30日以内に消えると案内されています（利用規約違反の疑いがある会話や、法律で求められる場合は除く）
  • 回答への「いいね・よくないね」やバグ報告を送ると、その会話は5年保たれます。仕事の会話では押さないのが無難です

2. 会社が契約したプランは扱いが違う

Claude の Team・Enterprise や、API（ほかのサービスに組み込んで使う形）は「商用」の扱いで、上の個人向けの設定とは別のルールです。入力を学習に使わない扱いになっているのが一般的です。

まず、いま自分がどちらのアカウントで使っているかを確かめてください。個人のメールアドレスでログインしているなら、個人向けのプランです。

3. 仕事で使うときの3つの線引き

学習の設定をオフにしても、入力した文章は Anthropic のサーバーに送られて処理されます。「学習されない」と「外に出ていない」は同じではありません。

  1. 会社のルールを先に見る：会社が「AIに顧客情報を入れない」と決めているなら、設定に関係なく入れない
  2. お客様との約束を見る：プライバシーポリシーや契約で、外部のサービスに預ける範囲をどう書いているか
  3. 本物の名前や番号が要るか考える：返信の下書き・要約・言い回しの直しなら、たいてい要りません

迷ったときの考え方は、こちらにもまとめています。

  • ChatGPTに顧客情報を入れていい？ 3つの線引き：customer-info-chatgpt.html
  • AIに個人情報を入れてしまったら（最初の10分でやること）：ai-nyuryoku-shimatta.html

4. Claude Code・デスクトップ版・Excel 連携でも同じ？（機密情報と情報漏洩）

チャット画面だけでなく、Claude Code（プログラミング用）、デスクトップ版、Excel などほかの道具とつなぐ使い方も増えています。気をつけることは2つです。

  • 個人のアカウントなら、1. の設定がそのままかかる：Anthropic は、個人向けプランで使う Claude Code の作業も「学習に使うか」の設定の対象だと案内しています。会社の Team・Enterprise・API で使うなら、2. の商用の扱いです
  • つないだ分だけ、送られる量が増える：フォルダ・表・メールを読ませる使い方では、自分で貼った一文ではなくファイルの中身ごとが送られて処理されます。顧客名簿や見積書の入ったフォルダを丸ごと渡す前に、要る部分だけにするか、伏せてから渡すのが安全です
  • 新しい機能は、使う前に公式ヘルプで確かめる：Excel 連携やエージェントのような新しい使い方は、保存や学習の扱いが更新で変わりやすい部分です

「Claude から情報漏洩した」という話の多くは、Claude そのものより、入れてよいか決めずに入れたことが原因です。社内で決めておくことは、社内ルールの例や社外秘をAIに使うときの線引きにまとめています。

いちばん確実なのは、貼る前に伏せ字にすること

「山田太郎様」を [氏名1]様、「090-1234-5678」を [電話1] にしてから貼れば、Claude に頼めることはほとんど変わりません。答えが返ってきたら、伏せ字を元に戻せば完成です。
