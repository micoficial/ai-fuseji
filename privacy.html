プライバシーポリシー（合同会社mico のブラウザ拡張機能）

最終更新日：2026年10月13日

この方針は、合同会社mico（以下「当社」）が Chrome ウェブストアと Microsoft Edge アドオンで提供する、次の拡張機能に適用されます。

  • PDF結合・整理（ローカルPDF結合）
  • 文字数カウント
  • WebP画像をJPG・PNGで保存
  • AI伏せ字（個人情報を伏せてAIへ、答えは元に戻す）
  • ローカルOCR
  • PDF圧縮

1. 収集する情報

当社の拡張機能は、利用者の個人情報、閲覧履歴、ファイルの内容、入力した文章、画像を、当社のサーバーやその他の第三者に送信・収集しません。PDFの結合・圧縮、文字数の計算、画像の変換、個人情報の伏せ字への置き換え、画像からの文字の読み取りなどの処理は、すべて利用者のパソコンの中（ブラウザの中）で行われます。

2. パソコンの中に保存する情報

拡張機能の設定、Pro版を有効にした記録（ライセンスキーそのものではなく、その確認結果）、文字数カウントの下書きと履歴、AI伏せ字の「いつも伏せる言葉」と伏せ字の対応表、ローカルOCRの読み取り履歴（Pro版）は、利用者のブラウザの中（拡張機能のストレージ）にだけ保存されます。AI伏せ字の元の文章と対応表は、ブラウザを閉じると消えます（Pro版の対応表の履歴は、利用者が消すまでブラウザの中に残ります）。当社がこれらを見ることはできません。

3. 通信を行う場合

Pro版を有効にするとき、入力されたライセンスキーが正しいかを確認するために、決済サービスGumroad（https://gumroad.com）のライセンス確認用の窓口（api.gumroad.com）に、ライセンスキーと商品IDだけを送信します。Gumroadでの購入に関する情報の扱いは、Gumroadのプライバシーポリシーに従います。

「WebP画像をJPG・PNGで保存」は、利用者が右クリックで選んだ画像を変換するために、その画像をそのサイトから読み込みます。読み込んだ画像は変換に使うだけで、当社やその他の第三者に送信しません。

「ローカルOCR」の文字認識エンジン（Tesseract.js）と言語データは、拡張機能の中に同梱しています。画像や読み取った文字を外部に送信しません。

4. 第三者への提供

当社は、拡張機能を通じて利用者のデータを集めないため、第三者に販売・提供することはありません。

Privacy Policy (browser extensions by mico LLC)

Last updated: October 13, 2026

Our extensions for Chrome and Microsoft Edge (PDF Merge, PDF Compressor, Character Counter, Save WebP as JPG/PNG, AI Redact, Local OCR) do not collect, transmit, or sell any personal data, browsing history, file contents, typed text, or images. All processing happens locally in your browser. Settings and Pro activation records are stored only in your browser. When you activate Pro, only the license key and product ID are sent to Gumroad's license verification endpoint (api.gumroad.com). "Save WebP as JPG/PNG" loads the image you right-click only to convert it locally. Local OCR bundles its recognition engine and language data; images and recognized text are never sent anywhere.
